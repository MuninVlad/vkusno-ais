# АИС «Вкусно и быстро»

Автоматизированная информационная система учёта заказов сети ресторанов «Вкусно и быстро».
Индивидуальная работа, тема №3. Скворцова Анастасия Дмитриевна, группа НБИбд-01-24.

**Сайт:** опубликован через GitHub Pages из папки [`docs/`](docs/) — ссылка указана в разделе
«About» справа (Settings → Pages). Вход — по учётным записям, которые выдаёт администратор.

## Состав репозитория

```
docs/           опубликованный сайт (GitHub Pages): страницы 1–3, зашифрованные страницы 2–3,
                файлы архива и данные (AES-256-GCM, ключ выводится из пароля пользователя)
app/            серверная часть (Flask): security, crypto, api, reports, archive, db, validation
templates/      шаблоны страниц серверной части (Jinja2)
static/         CSS, JS, логотип
sql/            schema.sql — создание БД, seed.sql — тестовые данные
storage/        файловый архив (диаграммы, скриншоты, документация)
tests/          автотесты (pytest) и проверка в браузере (Playwright)
static_src/     исходники версии для GitHub Pages
diagrams_src/   исходники диаграмм (Graphviz, Mermaid, Python)
docs_src/       генерация документов (ТЗ, пояснительная записка, руководства)
```

## Запуск серверной части на своём компьютере

```bash
pip install -r requirements.txt
python init_db.py      # БД, ключ шифрования и случайные пароли → instance/ (не публикуется)
python run.py          # https://localhost:8443
```

Пароли учётных записей записываются в `instance/accounts.json`. Браузер предупредит
о самоподписанном сертификате (учебный вариант): «Дополнительно» → «Перейти на сайт».

## Полезные команды

```bash
python -m pytest -q tests           # автотесты: функции и безопасность
python build_static.py              # пересобрать сайт для GitHub Pages (папка docs/)
python backup.py                    # резервная копия БД и архива (backups/, SHA-256)
python init_db.py --reset           # пересоздать БД с тестовыми данными
```
